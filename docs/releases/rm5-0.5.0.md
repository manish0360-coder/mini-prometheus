# Release notes — RM5 (runtime 0.5.0)

**Date:** 2026-09-15 · **Runtime:** 0.4.0 → 0.5.0 · **Contracts:** 0.4.0 (frozen) · **Constitution:** 1.1.0
· **Tag:** `rm5-complete`

RM5 — **Compounding Validation Experiment**. A deterministic, read-only measurement of whether accumulated verified
engineering experience measurably improves RM4 judgment against the deterministic RM1 oracle, on strictly held-out
analogous-but-non-identical cases within one fixed capability regime R*. This is a measurement milestone: **no new
capability, no cognitive primitive, no public contract** — it composes the frozen RM1–RM4 mechanisms.

## Result (within the deterministic oracle-internal world only)

- **Positive finite-corpus precedent effect.** Precedent marginal agreement **Arm 3 − Arm 2 = +42/121 (+0.3471)**
  (Arm 2 = 76/121; Arm 3 = 118/121), concentrated on **MANUFACTURABLE** held-out cases (42/45; NOT-class marginal
  0/76 — RM4's internal-verdict finding already handles adverse cases, so precedent cannot leak the oracle label).
- **Controls passed:** Arm 1 == Arm 2 exactly (121/121); cross-partition exact duplicates 0; deterministic
  checkpoint/fixture; RM1–RM4 byte-unchanged; reproducible report hash.
- Coverage 45/45 (MANUFACTURABLE) and 76/76 (NOT); false alarms 3/45 = 0.0667; excluded duplicates 0.

## Explicitly NOT demonstrated (valid scientific findings)

- **H2 — zero cautionary false alarms on MANUFACTURABLE controls (ceiling from RM4 H1): NOT MET (3/45).** Genuine
  precedent-driven misfires on near-miss designs — a real precision/safety trade-off, not a bug.
- **Strict monotonic compounding: NOT MET.** The marginal-vs-Arm2 curve is 0 → 0.3223 → 0.3554 → **0.3471** (final
  step decreases). The effect is a positive learning effect, **not** strict monotonic compounding.

## Independent review

Gemini: **`SCIENTIFICALLY SOUND AS A LIMITED INTERNAL VALIDATION`** (HIGH confidence). Oracle–model circularity
**LOW**; near-miss / synthetic-corpus generalization **MEDIUM**; no mandatory correction before C5/C6.

## Claim boundary

RM5 does **not** establish real-world manufacturing correctness, DFM correctness, cost/quality improvement,
superiority to human engineers, or deployment readiness. Claims are limited to the deterministic oracle-internal
experimental world and this synthetic, learnable corpus.

## Boundaries (by design)

Deterministic, read-only, additive. **No contract added** (suite frozen at `0.4.0`); `experiment/` is a leaf consumer
(import-linter + AST enforced), never writes the RM2 episode store (sinks: committed fixture + gitignored
`artifacts/evaluation/`); `partition`/`protocol` pure; no ML/embeddings; no Noetica store engine (Law 6); no
MiniFlyWire (Law 4). RM1–RM4 byte-unchanged.
