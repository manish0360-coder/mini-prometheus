# Release notes — RM2 (`rm2-complete`, runtime 0.3.0)

**Date:** 2026-07-25 · **Tag:** `rm2-complete` · **Runtime:** 0.2.0 → 0.3.0 · **Contracts:** 0.2.0 (frozen) · **Constitution:** 1.1.0

## Highlights

Mini Prometheus now **reuses its own verified experience** — the first rung of compounding. Run the same
`ManufacturingRequest` twice and the second run **retrieves and reuses** the prior verified `ProductionPlan`
+ `Verdict` deterministically, writing no duplicate episode. A reproducibility guard re-derives the plan and
confirms it matches before serving the reuse (verification-first).

- **`run_with_reuse(...)`** — the new entry point (RM1's `run` remains, unchanged).
- **Deterministic composite key** `(design_input identity, capability-model version)` — no stale-model reuse.
- **Purely additive:** RM1 is byte-unchanged and contracts stay frozen at `0.2.0`.

## Boundaries (by design)

The read side is a minimal index over MP's own episodes — **not** a memory/store/retention engine (that is
Noetica's lifecycle framework, deferred). No similarity retrieval, no learning that changes plans, no real
Velith/Noetica package integration yet (RM3/RM4).

## Verification

50 tests (RM1's 31 unchanged + 19 RM2); ruff clean; contracts frozen; bindings drift-stable. CI adds a
contract-freeze gate and an RM1 zero-diff gate against `rm1-complete`.
