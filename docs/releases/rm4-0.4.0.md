# Release notes — RM3 + RM4 (runtime 0.4.0, consolidated)

**Date:** 2026-08-03 · **Runtime:** 0.3.0 → 0.4.0 · **Contracts:** 0.4.0 (frozen) · **Constitution:** 1.1.0
· **Tags:** `rm4-complete` pending

This consolidated release cuts the accumulated, previously-unreleased work — **RM3 (Engineering Precedent
Reasoning)**, the ratified **RM1 correction**, and **RM4 (Engineering Judgment)** — into one runtime `0.4.0`.

## Highlights

- **RM3 — Engineering Precedent Reasoning (compounding rung 2).** For a new request, Mini Prometheus surfaces the
  most *relevant prior verified* cases and derives a supporting/cautionary/none signal (`PrecedentReport`).
  Deterministic structural relevance — no ML. Generalizes RM2's exact reuse to *analogous* cases.
- **RM4 — Engineering Judgment (compounding rung 3).** The first capability that reasons over the *whole case*.
  `run_judgment(episode, precedent_report)` assembles the internal `EngineeringSituation` and returns an advisory
  `EngineeringCritique` (situated findings + a supportive/cautionary/neutral assessment). First implementation:
  **Engineering Critique**.
- **Situated value:** a plan whose own RM1 verdict is `MANUFACTURABLE` yet resembles a `NOT_MANUFACTURABLE`
  precedent yields a **CAUTIONARY** critique — a signal isolated verification cannot produce.

## Boundaries (by design)

Deterministic, read-only, additive throughout. **No contract added by RM4** (suite frozen at `0.4.0`); the internal
`EngineeringSituation` primitive is never persisted, published, or given an external identity (extraction deferred
to the RM4 spec §12 gate). No planning/verification/retrieval re-derivation, no store/retention engine (Law 6), no
ML/embeddings, no MiniFlyWire (Law 4). RM1/RM2/RM3 byte-unchanged.

## Verification

**131 tests pass**; `mypy src` clean; contracts frozen at `0.4.0`; boundary + import-linter gates green. The
workstation now runs a pinned toolchain (Python 3.11, ruff 0.6.9 / mypy 1.11.2 / pytest 8.3.3) and a containerized
`docker compose ... verifier` at parity with the local venv.

## Known outstanding (not RM3/RM4 scope)

- **Ruff lint/format normalization** — the RM1–RM3 source predates any ruff standard; `ruff check`/`ruff format` are
  advisory in CI (`continue-on-error`) pending a one-time normalization chore.
- **No `LICENSE` file** — still an explicit owner IP decision (carried from RM1).
- **`EngineeringSituation` extraction** — deferred until a second consumer or cross-boundary coherence need (spec §12).
