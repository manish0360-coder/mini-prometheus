# Release notes — RM1 (`rm1-complete`, runtime 0.2.0)

**Date:** 2026-07-23 · **Tag:** `rm1-complete` · **Runtime:** 0.1.0 → 0.2.0 · **Contracts:** 0.2.0 · **Constitution:** 1.1.0

## Highlights

Mini Prometheus's first working manufacturing capability: the **`plan → verify → log`** loop. Give it a
real engineer `ManufacturingRequest` (a machined part: material, stock, operations, quantity, optional
STEP attachment) and it returns a verified, provenance-complete **`ProductionPlan`** and logs a
content-hashed **`ManufacturingEpisode`**.

- **Deterministic:** identical inputs produce identical plans, verdicts, and content hashes.
- **Verification-first:** a manufacturability oracle (implementing the Noetica `Verifier` protocol) grounds
  every plan; a non-manufacturable request is an honest logged outcome, not an error.
- **Honest provenance:** every plan claims manufacturability only, and records whether the design was
  Velith-verified or engineer-declared — it never implies engineering correctness it did not perform.

## Boundaries (what it does not do — by design)

Consumes Velith/Noetica by **contract** (fixtures), never re-implements them; never imports MiniFlyWire.
Does not parse STEP geometry, run real physics, or execute production. Real Velith/Noetica package
integration is RM2/RM3.

## Verification

31 tests (contract-compliance, unit, integration, boundary); lint clean; generated bindings drift-stable;
CI gate: drift → build → unit → contract → integration → boundary.
